# 대화 맥락, 음향적 특징 및 시각 정보의 단계적 융합에 따른 인공지능 발화 종료 예측 성능 변화 연구

> **이지우, 2026/10/26**

본 연구 주제는 고등학교 3학년 1학기에 진행한 로컬 AI 시스템 구축(https://github.com/happycoding0-0/Multimodal) 에서 얻은 아이디어다.

## 1. 연구 동기 및 목적

인간처럼 보고, 듣고, 말할 수 있는 로컬 인공지능 시스템을 개발하는 과정에서 음성 인식 기술의 한계를 발견하였다.

현재 개발 중인 시스템에서는 VAD(Voice Activity Detection)를 이용하여 사람의 음성활동을 감지하고, 일정 시간 동안 음성이 감지되지 않으면 그동안 누적된 오디오 데이터를 STT(Speech-to-Text) 모델로 전달하도록 구현하였다.

그러나 인간의 실제 대화에서는 음성활동의 종료가 반드시 발화의 종료를 의미하지 않는다. 예를 들어 어떤 사람이 대화 중 특정 단어를 기억하지 못하여 2초 이상 침묵하더라도, 상대방은 앞선 문장의 내용이나 말투를 통해 발화가 아직 끝나지 않았다고 판단할 수 있다.

반면 현재 구현한 시스템에서는 이러한 침묵을 발화 종료로 판단하여 발언이 끝나기 전에 오디오 데이터를 전달할 가능성이 있다.

이러한 문제를 해결하기 위해 단순히 침묵 시간을 측정하는 방식에서 벗어나, 발화의 문맥적 정보, 음향적 특징, 시각 정보를 단계적으로 추가했을 때 인공지능의 발화 종료 예측 성능이 어떻게 변화하는지 연구하고자 한다. 이를 통해 각 정보가 발화 종료 판단에 얼마나 기여하는지 분석하고, 인간과 더욱 자연스럽게 소통할 수 있는 인공지능 시스템의 발전 방향을 탐구하고자 한다.

## 2. 연구 문제 및 가설

> **첫 번째 질문 — 문제의 본질**
> 
> 인공지능은 사용자의 침묵이 발화 도중의 일시적인 멈춤인지, 실제로 발언을 마친 것인지 어떻게 판단할 수 있는가?

> **두 번째 질문 — 검증 방법**
> 
> 발화의 문맥적 정보, 음향적 특징, 시각 정보를 단계적으로 추가하면 인공지능의 발화 종료 예측 성능은 어떻게 변화하며, 각 정보는 예측 성능에 얼마나 기여하는가?

> **세 번째 질문 — 실제 시스템에 적용할 가치**
> 
> 추가적인 정보로 얻은 예측 성능 향상이 데이터 처리 비용과 응답 지연의 증가를 감수할 만큼 유의미한가?


인간은 상대방의 발화가 종료되었는지 판단할 때 단순히 침묵의 지속 시간만을 고려하지 않는다. 발화의 문맥적 완결성, 음성의 억양과 속도, 시선과 표정 등 다양한 정보를 종합하여 상대방이 말을 계속할 것인지 판단한다.

따라서 인공지능 역시 이러한 정보를 함께 활용하면 기존의 고정 시간 기반 방식보다 발화 종료 시점을 정확하게 예측할 수 있을 것이라고 가설을 설정하였다.

특히 서로 다른 특성을 가진 정보를 단계적으로 추가함으로써 각 정보가 예측 성능에 미치는 영향을 비교하고자 한다.

다만 정보의 종류가 증가한다고 반드시 예측 성능이 향상되는 것은 아니므로, 성능 향상 여부와 그 정도를 실험을 통해 객관적으로 검증하고자 한다.

## 3. 데이터 획득 및 분석 계획

본 연구에서는 인간의 실제 대화에서 나타나는 발화 지속과 발화 종료의 특징을 분석하기 위해 음성, 언어 및 영상 정보를 포함하는 데이터셋을 탐색하고자 한다.

음성 및 언어 데이터는 AI-Hub의 한국어 자유발화 음성 데이터와 국립국어원의 일상 대화 음성 말뭉치 등을 활용하고, 시각 정보가 포함된 데이터는 AMI Meeting Corpus와 같은 음성·영상 통합 데이터셋을 활용하는 방안을 검토한다.

데이터에서 침묵이 발생하는 구간을 추출하고, 해당 구간이 발화 도중의 일시적인 침묵인지 실제 발언권 양도에 해당하는지 구분한다.

이후 다음과 같은 정보를 분석하고자 한다.

- **문맥적 정보:** 발화 내용의 의미적·문법적 완결성, 문장의 연결 관계, 발화 지속 가능성
- **음향적 특징:** 침묵 지속 시간, 음높이, 음성 에너지, 발화 속도, 억양의 변화
- **시각 정보:** 시선 방향, 얼굴 표정, 입술 움직임, 고개 움직임

각 정보가 발화 종료 여부와 어떤 관련성을 가지는지 탐색하고, 이를 인공지능 모델의 입력 데이터로 활용하고자 한다.

또한 데이터셋마다 제공하는 정보가 다를 수 있으므로, 서로 다른 데이터셋의 결과를 직접 비교하기보다는 동일한 평가 데이터에서 각 정보의 추가 효과를 비교할 수 있도록 데이터를 구성할 계획이다.

## 4. 데이터 전처리 및 인공지능 모델링

수집한 음성 데이터를 동일한 샘플링 레이트로 변환하고, VAD 모델을 활용하여 음성활동 및 침묵 구간을 추출한다.

발화 내용은 STT 모델을 통해 텍스트로 변환하거나 데이터셋에서 제공하는 전사 정보를 활용한다. 이후 자연어 처리 모델을 이용해 발화의 문맥적 완결성과 발화 지속 가능성에 관한 특징을 추출한다.

음성 데이터에서는 음높이, 음성 에너지, 발화 속도 등의 특징을 추출하고, 영상 데이터에서는 얼굴 특징점 및 움직임 분석을 통해 시선과 입술, 고개 움직임 등의 시각적 특징을 수치화한다.

음성과 영상의 시간 정보를 동기화한 뒤, 추출한 특징들을 결합하여 인공지능 모델의 학습 데이터로 구성한다.

이후 Random Forest 또는 XGBoost와 같은 머신러닝 모델을 활용하여 발화 지속 여부를 예측하고, 다음과 같이 입력 정보를 단계적으로 추가하며 성능을 비교하고자 한다.

**1단계. 기존 고정 시간 기반 방식**

일정 시간 이상 음성활동이 감지되지 않으면 발화가 종료되었다고 판단하는 기존 방식을 기준 모델로 설정한다.

**2단계. 문맥적 정보 추가**

침묵이 발생하기 전까지의 발화 내용을 분석하여 문장의 의미적·문법적 완결성 등 문맥적 정보를 활용한 모델을 구성한다.

**3단계. 음향적 특징 추가**

문맥적 정보에 음높이, 음성 에너지, 발화 속도 및 억양 등의 음향적 특징을 추가하여 예측 성능의 변화를 분석한다.

**4단계. 시각 정보 추가**

문맥적 정보와 음향적 특징에 시선, 얼굴 표정, 입술 움직임 등의 시각적 특징을 추가하여 멀티모달 인공지능 모델을 구성하고 성능을 비교한다.

이를 통해 정보가 단계적으로 추가될 때 발화 종료 예측 성능이 어떻게 변화하는지 확인하고자 한다.

추가적으로 특정 정보만을 사용하거나 일부 정보를 제외한 모델도 비교하여 각 정보의 독립적인 기여도를 분석할 계획이다.

실시간 시스템에 적용할 수 있도록 모든 모델은 발화 종료 판단 시점까지 관측된 정보만 활용하도록 구성한다.

## 5. 모델 성능 평가 및 개선 계획

각 단계에서 구축한 모델의 예측 성능을 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1-score 등의 지표를 이용하여 평가한다.

특히 본 연구의 목적이 인간의 발화를 중간에 끊지 않으면서 적절한 시점에 응답하는 인공지능을 구현하는 데 있으므로 다음 두 가지 지표를 중요하게 고려한다.

**첫째, 조기 종료율(False Endpoint Rate)**

실제 발화가 완료되지 않았음에도 인공지능이 발화가 종료되었다고 판단하는 비율을 측정한다.

**둘째, 발화 종료 판단 지연 시간(Endpoint Latency)**

실제 발화가 종료된 시점부터 인공지능이 발화 종료를 판단하기까지 걸리는 시간을 측정한다.

단순히 침묵을 오랫동안 기다리면 조기 종료율은 감소할 수 있지만 인공지능의 응답 속도가 느려질 가능성이 있다. 따라서 두 지표 사이의 균형을 함께 분석하고자 한다.

이후 각 단계에서 측정한 성능을 비교하여 문맥적 정보, 음향적 특징, 시각 정보의 추가에 따라 예측 성능이 얼마나 변화하는지 정량적으로 분석한다.

또한 특징 선택, 모델 하이퍼파라미터 조정, 학습 데이터의 불균형 개선 등을 통해 성능을 향상시키고자 한다.

이를 통해 단순히 많은 정보를 사용하는 것이 유리한지, 아니면 특정 정보의 조합이 더 효과적인지를 확인하고자 한다.

## 6. 기대 효과 및 후속 연구

본 연구를 통해 단순히 음성 신호의 유무를 감지하는 것과 인간의 의사소통 의도를 이해하는 것이 서로 다른 문제라는 점을 탐구하고자 한다.

특히 문맥적 정보, 음향적 특징, 시각 정보를 단계적으로 추가하며 각 정보가 인공지능의 발화 종료 판단에 어떠한 영향을 미치는지 분석함으로써, 자연스러운 인간과 인공지능의 상호작용을 위해 필요한 정보의 종류와 그 중요성을 파악할 수 있을 것으로 기대한다.

또한 정보의 종류가 증가함에 따라 예측 성능뿐 아니라 데이터 처리량과 연산 비용도 증가할 수 있으므로, 로컬 인공지능 시스템에서 성능과 실시간 처리 속도 사이의 관계도 함께 탐구하고자 한다.

향후 대학에서는 자연어 처리, 음성 신호 처리, 컴퓨터 비전 및 멀티모달 인공지능을 심화 학습하여 서로 다른 형태의 정보를 효과적으로 융합하는 방법을 연구하고 싶다.

나아가 단순한 발화 종료 예측을 넘어 대화 상대의 발언권, 의도, 상황적 맥락까지 종합적으로 이해하고 적절한 시점에 반응하는 실시간 멀티모달 인공지능 시스템으로 연구를 확장하고자 한다.

궁극적으로는 인공지능이 단순히 인간의 말을 인식하고 응답하는 수준에서 벗어나, 인간의 의사소통 과정을 이해하고 자연스럽게 상호작용할 수 있도록 만드는 것이 목표이다.
